# DJ Dojo

Learn to DJ in your browser, one skill at a time.

Plug in a **Pioneer DJ DDJ-FLX4** and the game reads its knobs, faders and jog
wheels directly, then scores what you do: how tight your beatmatch is, whether
you started on the right bar, how clean your bass swap was. No controller with
you? Every lesson also works on the **keyboard**.

There is nothing to install and no account. Progress is saved in your browser.

## Play

Open `index.html` through any local web server:

```bash
npm start
```

then visit <http://localhost:8080>. (Once GitHub Pages is switched on for this
repo, the game is also playable straight from its Pages link.)

### Using the DDJ-FLX4

1. Use **Chrome or Edge** on a computer (they can talk to MIDI devices; Safari and Firefox on iOS cannot).
2. Plug the controller in by USB and **close rekordbox / Serato** — only one app can use it at a time.
3. Click **connect controller** (top right) and allow MIDI access.
4. Sound comes out of your **computer's speakers or headphones**, not the controller. Use wired ones: Bluetooth adds a delay that makes timing drills unfair.

The on-screen mixer mirrors your hardware. If a lesson needs a fader somewhere
specific, it shows a short checklist and waits for you to move it.

Tip: nudge with the **outer edge** of the jog wheel, as you would on real gear.

### Using the keyboard

Left hand runs Deck 1, right hand runs Deck 2. Tap a key for a small step, hold
it to glide, hold `Shift` for finer moves.

| Control | Deck 1 | Deck 2 |
| --- | --- | --- |
| Play / Cue | `S` / `A` | `K` / `J` |
| Nudge back / forward (jog) | `Z` / `X` | `N` / `M` |
| Tempo slower / faster | `Q` / `W` | `U` / `I` |
| Channel fader down / up | `1` / `2` | `7` / `8` |
| Bass (LOW) down / up | `E` / `R` | `O` / `P` |
| Filter | `D` / `F` | `L` / `;` |
| Headphone cue | `V` | `B` |
| Sync (free play) | `G` | `H` |

Crossfader: `←` `→` · Tap: `Space` · Confirm: `Enter` · Restart lesson: `Backspace`

## The lessons

Each lesson explains one idea, lets you try it, then gives a score out of 100,
up to three stars, and a tip based on what you actually did. One star unlocks
the next lesson. The **↺ Restart** button (top right) starts the lesson over at
any time.

| # | Lesson | What you learn |
| --- | --- | --- |
| **Rhythm** | | |
| 1 | Tap the Beat | Feel the steady pulse |
| 2 | Find the One | Count bars (groups of 4 beats) |
| 3 | Hear the Phrase | Spot 8-bar section changes |
| **Beatmatching** | | |
| 4 | Faster or Slower? | Hear which track is drifting ahead |
| 5 | Ride the Tempo Fader | Tiny, precise fader moves |
| 6 | Tempo by Ear | Match speed with the BPM display hidden |
| 7 | Nudge into Step | Line the beats up with the jog wheel |
| 8 | The Full Beatmatch | Both together, then hands off for 8 bars |
| **Phrasing** | | |
| 9 | Drop on the One | Start a track on the section change |
| **EQ & Transitions** | | |
| 10 | The Bass Swap | Hand the bass from one track to the other |
| 11 | The 16-Bar Blend | A full transition, with sync helping |
| 12 | The Full Mix | Beatmatch by hand, then blend |
| **Harmony** | | |
| 13 | Keys that Fit | Which musical keys blend (Camelot wheel) |

**Free Play** gives you two open decks with the built-in tracks or your own
audio files (the game estimates their tempo; you can correct it).

## The music

The five practice tracks are generated by code when you start a lesson, so
there is nothing to download or license. They are simple on purpose and have an
exact, known tempo and structure (8-bar sections with a drum fill and a crash at
each change), which is what lets the game score you fairly.

## How it is built

Plain HTML, CSS and JavaScript modules. No build step, no dependencies.

```
js/audio/    sound: track generator, two decks + mixer, tempo detection
js/input/    control bus, keyboard, Web MIDI, controller profiles
js/game/     lessons, scoring maths, saved progress
js/ui/       screens, waveforms, on-screen mixer
```

Every input device speaks one shared "control bus" language (`a.play`,
`b.tempo`, `xfader` ...), a bit like every keyboard brand producing the same
letters. Lessons only listen to the bus, so they never care which device you
hold.

### Adding another controller

1. Copy `js/input/profiles/ddj-flx4.js` and change the MIDI numbers to match your controller (Settings shows live messages as you move things).
2. Add it to the list in `js/input/profiles/index.js`.

That is all: every lesson then works with it.

### Tests

```bash
npm test
```

runs the unit tests (track generator, tempo detection, scoring, controller map).

`node tools/e2e.mjs --midi` (needs Playwright, with `npm start` running) has a
robot play every lesson in a real browser and checks a pretend DDJ-FLX4 end to
end.
